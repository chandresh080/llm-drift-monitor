Methodology

Three tests compare the latest cycle with the reference window: a Kolmogorov–Smirnov test on response lengths, a Fisher exact (or z) test on the non-empty response rate, and a paired Maximum Mean Discrepancy permutation on sentence embeddings. Benjamini–Hochberg controls the false discovery rate across the family. Response availability is a quality signal, not a distribution verdict.
