How are these tests used?

Three statistical tests compare the latest cycle with the reference window: a Kolmogorov–Smirnov test on response lengths, a Fisher exact (or z) test on the non-empty response rate, and a paired Maximum Mean Discrepancy permutation on sentence embeddings. Benjamini–Hochberg correction controls the false discovery rate across the family; an alert additionally requires the same verdict on consecutive cycles.

Response availability is a quality signal, not a distribution verdict: its flag is reported separately and never changes the shift headline above. The semantic test permutes complete response sets per matched prompt, because the panel probes the same prompts every cycle. Full methodology and measured performance are in the repository's METRICS.md.
